# v3 — рабочий кандидат, не опубликован

Этот документ имеет приоритет над унаследованными README/HANDOFF/START_HERE версии v2 в части новых изменений и результатов тестирования. История v2 сохранена, но её проверки не считаются повторёнными для v3.

## Изменения
- На schools.html и en/index.html добавлены пять однотипных биографических карточек и 11 связей педагог → ученик, каждое ребро с источником. Три связи только по очерку помечены пунктиром и словами; это не архивное подтверждение.
- Новые RU/EN сведения генерируются из общего двуязычного массива enhancements.py. Прежние тексты не удалены; старый русский обзор оставлен перед подробными карточками. Новый раздел EN передаёт те же новые факты, но полный литературный перевод всех прежних русских абзацев в этой работе не выполнялся.
- Дополнительные фильтры: жанр, состав, источник, статус сложности. Данные берутся из описаний существующих десяти карточек. Издательство не подменяется доменом библиотеки. Все записи имеют статус «не оценено по нотам»: фиктивные уровни не назначались. Для реальных уровней нужен разбор изданий и утверждение шкалы преподавателем.
- Явная подпись ИИ-портрета RU/EN; исправлен русский skip-link на английской странице; усилен видимый фокус, стили новых блоков адаптивны.
- Добавлен 404.html. Его файл не заставляет сервер автоматически отдавать его при ошибке: назначение ErrorDocument/аналогичного механизма хостинга ещё требуется. Никакие серверные настройки не применялись.
- build.py вызывает enhancements.py как завершающий этап. Ручное редактирование site/ не требуется. Добавлен параметр --lastmod для воспроизводимого значения карты сайта; без него остаётся текущая дата. Одностраничный artifact.html не является целевым результатом v3 и не содержит всех новых блоков.

## Команды
```sh
python3 build.py --release --domain https://blazhevich.tech --lastmod 2026-11-09
python3 tools/check_site.py
python3 tools/test_v3.py
```
Дата 2026-11-09 фиксирует эту редакцию. При содержательных изменениях её обновляет редактор, не механизм случайного изменения дат.

## Проверено фактическим запуском
- Штатный checker: семь содержательных страниц, 321 локальная ссылка/путь, ошибок нет. Дополнительный 404 проверен наличием файла, но не серверной отдачей.
- Node: синтаксис script.js и выполнение функции фильтра на данных реального HTML с имитацией DOM. По 864 комбинации фильтров RU и EN, поиск тубы — четыре из десяти, пустой запрос-результат корректен. Это тест логики, НЕ браузерный тест видимости и взаимодействий.
- Повторная сборка с фиксированным --lastmod побайтно идентична. 40 файлов: прежние 39 и 404.html.
- Сопоставление карточек двух языков, наличие всех источников и ключевых подписей проверено программно.

## Не выполнено / блокеры
Публикация: нет проверенного авторизованного доступа к public_html Hostinger. Текущее состояние удалённых файлов и причина заглушки здесь не установлены. Нельзя подменять сайт старой версией или трогать подписки.
Браузер: Chromium/Playwright отсутствуют. Реальный рендер, скриншоты 360 px/desktop, keyboard UX и контраст новых блоков в браузере не проверены. До публикации требуется визуальная приёмка.
Факты: использованы ранее прочитанные источники, перечисленные ниже. Новая независимая архивная сверка, права на дополнительные портреты, детальная дискография/издания не выполнены. Не заполненные поля явно обозначены, а не выдуманы. Полная вычитка английского носителем не выполнена.
Статус сложности: фильтр внедрён, экспертные оценки нот ещё отсутствуют. Новые страницы персоналий не создавались — карточки встроены в существующие разделы, чтобы сохранить архитектуру.

## Публикация после доступа и визуальной приёмки
Сначала резервная копия текущих файлов безопасным штатным способом без публичных резервных архивов. Проверить именно public_html нужного сайта. Загружать только содержимое site/; исходники, тесты и документы на хостинг не выкладывать. Не удалять неизвестные файлы, .htaccess и почтовые настройки.
Проверить фактическую очередность index/default; не считать default.php безусловно безвредным. При конфликте менять только подтверждённую заглушку после резервирования. Удалить загруженный публичный ZIP после успешной проверки и сохранения исходника локально.
С внешней сети проверить 7 страниц по содержимому и HTTP 200, robots/sitemap, OG image MIME, /en/, перенаправления и настоящую 404. 301/308 записывать как наблюдаемый факт, не перестраивать сервер ради совпадения цифры. В sitemap семь содержательных URL, 404.html не индексировать.
Никаких DNS, SSL, VPN, подписок, покупок, сбора средств, кошельков или секретов эта версия не меняет.
