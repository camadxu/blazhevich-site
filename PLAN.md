## 3. Этап 1. «Лента» — ежедневный дайджест по медным

### 3.1 Что видит посетитель

- **Панель на главной** под первым экраном (`.block` сразу после hero): заголовок «Лента», дата выпуска, 5 карточек, чипы фильтра по инструментам, ссылка «Весь архив».
- **Раздел `/news/`**: текущий выпуск целиком + архив по дням, пермалинк выпуска `/news/2026-11-17.html`.
- **`/feed.xml`**: RSS последних 50 позиций — одновременно канал доставки и сигнал для агрегаторов.
- **Подписка**: письмо раз в неделю (воскресенье) — сводка; ежедневная рассылка опционально, по умолчанию выключена.
- **Без JavaScript** виден последний собранный выпуск (он запечён в HTML). JS только подтягивает более свежий.

### 3.2 Данные

Каталог `data/news/` в репозитории:

```
data/news/sources.json        # конфиг источников (см. BRASS-NEWS-SOURCES.md)
data/news/2026-11-17.json     # выпуск
data/news/index.json          # последние 90 выпусков: дата, счётчик, топ-3 заголовка
```

Схема выпуска (не менять без правки `build.py` и этого файла):

```json
{
  "release": "2026-11-17",
  "generated_at": "2026-11-17T03:12:40Z",
  "counts": {"fetched": 412, "kept": 14, "dropped_dupes": 96},
  "items": [{
    "id": "2026-11-17-03",
    "title": "…",
    "url": "https://…",
    "source": "Last Row Music",
    "source_weight": 3,
    "lang": "en",
    "published": "2026-11-16",
    "summary": "2–3 предложения своими словами, без копирования чужого текста",
    "instruments": ["trombone"],
    "kinds": ["vacancy"],
    "score": 7.5,
    "cluster": [{"source": "ITA", "url": "https://…"}]
  }]
}
```

Правила: `summary` — пересказ, не копия; всегда сохраняется ссылка на первоисточник; максимум 15 позиций в выпуске; сортировка по `score`, затем по дате; запись без `published` не публикуется.

### 3.3 Пайплайн

Скрипт `news_agent.py` (Python 3, `feedparser` + `requests`), живёт на VPS, в репозиторий кладём только результат и сам скрипт (без ключей).

1. **fetch** — RSS по всем источникам из `sources.json` (12 подтверждённых фидов: Slipped Disc, 4barsrest, Last Row Music, trombone.net, HornMatters, VAN, UK Jazz News, Jazz.ru, ТАСС, 4 сабреддита, jazzquad).
2. **supplement** — для источников без RSS: Firecrawl `scrape` (страница → markdown) или `search` (5–10 запросов из `BRASS-NEWS-SOURCES.md`, раздел C). Лимит кредитов в сутки — из конфига, по умолчанию 20.
3. **dedupe** — по canonical URL и по триграммам заголовка; окно 45 дней; хранить хэши в `data/news/seen.json`.
4. **score** — правила, без LLM: словарь инструментов (тромбон, труба, валторна, туба, эуфониум, корнет, флюгельгорн, брасс-бэнд) × словарь типов (конкурс, аудиция/вакансия, премьера, назначение, память/некролог, фестиваль, альбом, мастер-класс) × свежесть × вес источника. Порог отсечки — в конфиге, подбирается по первым выпускам.
5. **cluster** — одно событие = одна карточка, 2–4 ссылки в `cluster`.
6. **emit** — `data/news/ГГГГ-ММ-ДД.json` + обновление `index.json` + лог `counts`.
7. **publish** — один коммит в `main` через GitHub API (fine-grained token, `contents: write`, только этот репозиторий). CI пересобирает тест.

**Расписание.** GitHub Actions, `.github/workflows/agent-daily.yml`, `0 5 * * *`. Резерв — cron на `nlvps` в 09:30 с защитой от повтора: если выпуск за сегодня уже есть или `index.json` моложе 20 часов, прогон пропускается.

**Бюджет и деградация.** RSS — бесплатно. Firecrawl: 10–20 страниц в день ≈ 300–600 кредитов/мес; бесплатный тариф 1000 кредитов не покрывает расчётную нагрузку (1500/мес при 30 страницах + 10 поисках в день), остаток до 07.12.2026, дальше решается — план за $19 (5000 кредитов) или режим «только RSS». Скрапить только в режиме **markdown (1 кредит/страница)**, не JSON (5 кредитов/страница) — иначе расход вырастает в 5 раз. При `402`/`429` — режим «только RSS», письмо владельцу, выпуск всё равно выходит.

### 3.4 Свежесть на проде

Прод обновляется вручную, поэтому статический выпуск на проде отстаёт от теста. Решение из трёх частей:

1. **Статика** — последний закоммиченный выпуск запечён в HTML: SEO, пермалинк, работа без JS.
2. **Живой JSON** — на сервере отдаётся `/news/today.json` с `Access-Control-Allow-Origin: https://blazhevich.tech`, кэш 5 минут. Панель при загрузке делает один `fetch`, и если `release` новее запечённого — заменяет содержимое. Нет ответа — остаётся статика. Никаких сторонних скриптов.
3. **RSS** — отдаётся сборкой; обновляется при каждом деплое прода (раз в неделю силами владельца достаточно).

Если раздел вырастет — вынести на отдельный поддомен (отдельная запись DNS, отдаёт сервер). Это решение владельца, не по умолчанию.

### 3.5 Правки сборщика

- `build.py`: `PAGES['news.html'] = (['news'], 'Лента — новости медных инструментов', '…')`; `NAV_RU` — пункт «Лента» последним (в меню уже 8 пунктов, это на грани; главный вход — панель на главной, меню — для архива); чтение `data/news/index.json`; генерация `/news/`, `/news/ГГГГ-ММ-ДД.html`, `/feed.xml`; панель в `src/ru/index.html` как секция рядом с hero; sitemap — добавить выпуски.
- Рендер панели и выпуска — отдельные функции в `build.py`, без внешних зависимостей (стандартная библиотека + `xml.sax.saxutils` для RSS).
- EN-версия ленты — **не на этом этапе**: сначала RU, потом решаем (см. §8).
- Вёрстка — в палитре V6 (`--paper:#e8dbbf`, тёмные зоны `--deep-*`).
- **Правило имён:** только `data-agent-*`. `data-catalog-filter`, `id="search"`, `id="count"` не возвращать — это запрещено `tools/test_v3.py:19`.

### 3.6 Подписка на письмо

- `subscribe.php` кладётся в деплой сборщиком; подписчики пишутся в файл **вне** `web-root`; сервер забирает их по токену раз в сутки.
- Двойное подтверждение обязательно; отписка — ссылкой в каждом письме; SPF/DKIM на домене настраивает владелец; отправка — через сервис рассылок.
- Хранить только почту и дату; никаких других полей.

### 3.7 Наблюдаемость

- Лог `/var/log/news-agent.log` с ротацией.
- Письмо владельцу, если: 0 отобранных позиций, ошибка сети > 3 источников подряд, исчерпан бюджет Firecrawl, коммит не прошёл.
- Идемпотентность: повторный прогон за ту же дату перезаписывает выпуск, а не дублирует.

### 3.8 Приёмка этапа

- На тесте панель показывает сегодняшний выпуск, 5 карточек, чипы фильтруют без перезагрузки.
- `/news/` и пермалинк открываются, canonical верный, в sitemap попали.
- `/feed.xml` валиден (проверить любым валидатором RSS), 50 позиций.
- При выключенном JS виден вчерашний выпуск и все ссылки.
- `python build.py && python tools/check_site.py && python tools/test_v3.py` — зелёные.
- Ссылки в выпуске ведут на первоисточники, ни одна карточка не состоит из одного пересказа без ссылки.

**Оценка:** 3–4 дня работы агента + 1 день на серверную часть и cron.

## 4. Этап 2. Окно агента: чат на сайте

Лента и чат живут в одном окне: лента — содержимое по умолчанию, чат — вкладка внутри того же блока.

### 4.1 Почему нужен свой ключ

Подписки ZCode, Codex и Claude привязаны к браузеру и CLI, публичного API для встраивания у них нет. Значит, для чата нужен собственный ключ провайдера модели, и жить он должен **только на сервере** — в браузер не попадает никогда.

### 4.2 Провайдер и стоимость

| Провайдер | Цена | Один ход диалога (≈1500 вх. + 400 исх. ≈ 1900 токенов) |
|---|---|---|
| GigaChat Lite | 0,065 ₽ за 1k токенов | ≈ 0,12 ₽ |
| YandexGPT Lite (резерв) | 0,20 ₽ за 1k токенов | ≈ 0,38 ₽ |

Ориентир бюджета: 150 ходов в сутки ≈ 570 ₽/мес. Итоговый выбор провайдера — за владельцем; цифры выше — оценка по опубликованным тарифам, проверяется на первом же подключении.

### 4.3 Как устроено

- **Прокси:** Python stdlib `ThreadingHTTPServer` на `nlvps`, слушает `127.0.0.1`, наружу — только через Caddy по пути `/agent/*`, вырезанному из Basic auth. OAuth-токен провайдера обновляется на сервере (время жизни ~30 минут).
- **CORS:** allow-list `https://blazhevich.tech`, `https://www.blazhevich.tech`, локальная сборка. Всё остальное — отказ.
- **CSP:** в `.deploy/htaccess` добавить `connect-src 'self'`; iframe не используется (`frame-ancestors 'self'` остаётся как есть).
- **Лимиты:** 20 сообщений в час на IP, общий суточный потолок ~150 ходов. При исчерпании — честное сообщение, а не тишина.
- **Контекст:** top-k по выпускам ленты и текстам страниц считается на сервере; модель в интернет не ходит, ответы опираются на материалы сайта и ссылки на источники.
- **UI:** вкладка «Агент» в том же окне, что лента; дисклеймер «ответы формируются ИИ и могут содержать ошибки»; каждая фактическая ссылка — на первоисточник.

### 4.4 Приёмка этапа

- Ответ приходит за < 10 с, в ответе есть источники.
- Ключ не встречается ни в HTML, ни в JS, ни в сетевых ответах браузера.
- Лимит на IP срабатывает и объясняет себя; при выключенном чате лента продолжает работать.
- Снаружи доступен только `/agent/*`; Basic auth на остальном хосте не сломан.
- `build.py`, `check_site.py`, `test_v3.py` — зелёные.

**Оценка:** 1,5–2 дня (прокси, лимиты, UI, проверки).

## 5. Этап 3. Ноты: «всё или ничего»

### 5.1 Принцип

Решение владельца: **что выкладываем — то целиком и бесплатно; чего не выкладываем — того на сайте нет**. Ни freemium, ни «первых страниц», ни превью с водяным знаком, ни выдачи по письму, ни формы «запросить доступ».

### 5.2 Что публикуется

- Произведения самого Блажевича: он умер в 1942 году, его сочинения — общественное достояние с 01.01.2013. Полные файлы, один клик, без регистрации.
- Первым — школа для раздвижного тромбона, издание 1936 года: файл уже лежит в репозитории (`assets/library/scores/school-slide-trombone-1936.pdf`).
- Дальше — остальные сочинения Блажевича по мере сверки с источниками.

### 5.3 Что не публикуется

Чужие редакции, переложения и современные издания — их в каталоге нет вообще: ни карточки, ни тизера, ни пометки «скоро». Карточка каталога либо ведёт на полный файл, либо её не существует.

### 5.4 Оговорка на странице

На странице каталога — короткий абзац: какие издания являются общественным достоянием (сочинения самого Блажевича), а какие представляют собой чужие редакции и потому не публикуются. Без юридических обещаний и без «свяжитесь с нами».

### 5.5 Деньги — отложены

Сейчас на сайте нет ни платежей, ни подписок, ни рекламных блоков. Что известно про рынок, чтобы решать потом, а не сейчас:

- рекламные сети при 2–5 тыс. визитов дают порядок 0,3–1,5 тыс. ₽/мес — это фон, а не модель;
- прямой спонсор ленты — 5–15 тыс. ₽/мес, но требует посещаемости и медиакита;
- продажа нот упирается в то, что публикуемое и так свободно, а чужое публиковать нельзя;
- реальная маржа — в услугах: набор, транспозиция, изготовление партий.

**Ничего из этого не строим, пока владелец не скажет.** Когда скажет — первым идёт раздел услуг, а не платежи за ноты.

### 5.6 fal.ai

Как чат-бэкенд не подходит: оплата за вызов, подписки нет, текстовой модели в наборе нет. Остаётся утилитой для медиа (реставрация сканов, распознавание, повышение разрешения). Генерация изображений на научном сайте не применяется.
