# Передача проекта: сайт Blazhevich

Документ для агента, который будет размещать сайт на сервере. Домен сайта: **blazhevich.space**. Домен и DNS заказчик подключает сам.
Ничего не публиковалось, домен не покупался, DNS не менялся.

## 1. Что реализовано

* **Семь страниц.** Шесть русских (`index`, `biography`, `usa`, `schools`, `concertos`, `about`) и одна английская (`en/index.html`). Английская страница содержит все разделы русской версии на одной странице: ноты, записи, полную биографию, Америку, школы тромбона, концерты, источники. Устройство описано в README.md.
* **Поиск по нотам** на главной и в английской версии. Поиск по названию и фильтр по инструменту (тромбон / туба), счётчик результатов, сообщение «Ничего не найдено». Без JavaScript видны все карточки.
* **«Ноты» — это ссылки на внешние библиотеки и описания** (Московская консерватория, classON, IMSLP, сайты исследователей). Собственных PDF и аудиофайлов на сайте нет, и это сделано намеренно: права на конкретные издания не проверены.
* **Переключение RU/EN.** Кнопка EN/RU в меню и ссылка в подвале. У главных страниц в публичной сборке есть `hreflang`.
* **Сноски [1]–[11]** у конкретных утверждений ведут к списку источников на `about.html` (`about.html#s1` … `#s11`). У дополнительных источников [8]–[10] указан статус проверки. Английская страница ведёт собственный список из 7 источников с той же нумерацией [1]–[7].
* **Мобильная вёрстка.** Колонки складываются, таблица концертов на узком экране превращается в карточки, меню переносится на две строки. Первый экран статичен, кроме мягкого появления; на телефонах и сенсорных экранах отключён и параллакс. При системной настройке «уменьшить движение» анимации отключены везде.
* **Шрифты лежат локально** в `assets/fonts/`. Это Cormorant Garamond (заголовки), Onest (текст) и Old Standard TT (надпись BLAZHEVICH и логотип в шапке), подмножества кириллицы и латиницы, всего около 0,5 МБ. Google Fonts сайт не использует. Полные тексты лицензий SIL OFL 1.1 с правообладателями лежат рядом (`OFL-*.txt`).
* **Метаданные:** заголовок и описание у каждой страницы, Open Graph и превью 1200×630 (`assets/og-image.jpg`), иконка (встроенный SVG).
* **Доступность:** ссылка «Перейти к содержимому», видимый фокус клавиатуры, `aria-live` у счётчика результатов, подписи к полям, один `<h1>` на страницу.
* Изменения в текстах по итогам сверки источников перечислены в разделе «Изменения в этой передаче».

## 2. Как задать основной URL сайта при сборке

Адрес передаётся параметром `--domain` вместе с `--release`:

```bash
python3 build.py --release --domain https://blazhevich.space
```

* Укажите схему (`https://`) и адрес **без косой черты в конце**. Если сайт лежит во вложенной папке, передайте её полный адрес, например `https://example.com/blazhevich`.
* Без `--domain` команда `--release` завершится с ошибкой: сборщик не станет собирать публичную версию без адреса.
* Если сайт размещается зеркалами (например, в РФ и США), собирайте обе копии с **одним и тем же** `--domain`, адресом основного сайта.
* `--domain` без `--release` даёт черновик с полными адресами в Open Graph и canonical, но с `noindex`. Обычно это не нужно.

## 3. Как убрать плашку «не опубликовано» и запрет индексации

И плашка, и запрет индексации зависят только от флага `--release`. Вручную HTML править не нужно.

| | `python3 build.py` (черновик) | `python3 build.py --release --domain …` |
|---|---|---|
| `<meta name="robots">` | `noindex,nofollow` | `index,follow` |
| Плашка «Предварительный просмотр · не опубликовано» / «Preview · not published» | есть | нет |
| canonical, og:url, hreflang | нет | есть |
| `og:image` | относительный путь | полный адрес |
| `sitemap.xml`, `robots.txt` | не создаются (и удаляются, если были) | создаются |

**Папка `site/` в архиве собрана как ПУБЛИЧНАЯ версия для https://blazhevich.space** (индексация разрешена, плашки нет, canonical, sitemap.xml и robots.txt указывают на этот адрес). Основным адресом считается https://blazhevich.space без www; если сервер будет отдавать сайт по другому адресу (www или http), настройте постоянное перенаправление на него либо пересоберите с нужным `--domain`.
Проверить режим можно командой `python3 tools/check_site.py`: строка «Режим:» покажет ПУБЛИЧНЫЙ или ЧЕРНОВИК.

## 4. Как формируются canonical, sitemap.xml и robots.txt

Всё формирует `build.py` из значения `--domain` (далее `D`):

* **canonical:** для `index.html` это `D/`, для `en/index.html` — `D/en/`, для остальных страниц `D/<имя>.html`, например `D/usa.html`. Тот же адрес попадает в `og:url`.
* **hreflang:** только на `index.html` и `en/index.html` (`ru → D/`, `en → D/en/`). У внутренних русских страниц английских аналогов нет, поэтому на них hreflang не ставится.
* **sitemap.xml:** семь адресов: `D/`, `D/biography.html`, `D/usa.html`, `D/schools.html`, `D/concertos.html`, `D/about.html`, `D/en/`. Поле `lastmod` равно дате сборки.
* **robots.txt:**
  ```
  User-agent: *
  Allow: /
  Sitemap: D/sitemap.xml
  ```
* Ссылки между страницами относительные (`usa.html`, `about.html#s3`, `../index.html`) и от домена не зависят.
* Адрес `D/en/` предполагает, что сервер отдаёт `index.html` для каталога. В nginx это делает `index index.html;` (пример в README.md).

## 5. Внешние сервисы и работа без интернета

* **Ресурсы, которые грузятся при открытии страницы** (скрипты, стили, шрифты, изображения), все локальные. CDN, Google Fonts, счётчиков, аналитики, cookies, форм и сторонних встраиваний (iframe) нет.
* **Внешние ссылки** — обычные гиперссылки, по которым переходит сам посетитель. Ведут на сайты: mosconsv.ru, conservatory.ru, classon.ru, gnesin.ru, krugosvet.ru, litres.ru, cyclowiki.org, ru/en.wikipedia.org, commons.wikimedia.org, imslp.org, jayfriedman.net, yeodoug.com, thelasttrombone.com, caleblambertlowbrass.com, static1.squarespace.com (PDF диссертации Ламберта), trombone.net, trombone.org, bu.edu, music.uga.edu. Полный список выводит `tools/check_site.py`.
* **Без интернета работает** весь сайт: все страницы, оформление, шрифты, изображения, поиск и фильтр, переключение языков, сноски. Не открываются только переходы по внешним ссылкам: ноты в библиотеках, записи Ламберта, источники.
* Для сборки интернет не нужен.

## 6. Какие проверки выполнены, а какие нет

### Выполнено при подготовке этой передачи (8 ноября 2026)

Финальный архив отличается от кандидата только этим файлом HANDOFF.md, и после его упаковки повторно выполнены проверки 1–3.

1. **Комплектность и ссылки** (`tools/check_site.py`) на папке `site/` из архива (публичная сборка для https://blazhevich.space): 7 из 7 страниц на месте, проверено 250 локальных ссылок и путей (href, src, srcset, url() в fonts.css) — **0 ошибок**. Битых ссылок, отсутствующих якорей, повторяющихся id и внешних загружаемых ресурсов нет, `<h1>` на каждой странице ровно один.
2. **Воспроизводимость сборки.** `python3 build.py --release --domain https://blazhevich.space` в чистой папке собирает `site/`, **побайтно идентичную** `site/` из архива (проверено `diff -r`).
3. **Публичные метаданные для blazhevich.space:** `index,follow`, плашки нет; canonical `https://blazhevich.space/` (на `concertos.html` — `https://blazhevich.space/concertos.html`, на английской странице — `https://blazhevich.space/en/`); `og:image` = `https://blazhevich.space/assets/og-image.jpg`; sitemap.xml на 7 адресов и robots.txt со ссылкой на `https://blazhevich.space/sitemap.xml`. Черновая сборка (`python3 build.py`) тоже проверена: `noindex`, плашка есть, canonical/sitemap/robots отсутствуют, 0 ошибок.
4. **Проверка в браузере** (Chromium без интерфейса, через Playwright) на черновике и на публичной сборке для blazhevich.space (открывалась локально, с диска), все 7 страниц, ширина 1366 и 390 px:
   * горизонтальной прокрутки нет, ошибок JavaScript и консоли нет;
   * **все внешние запросы были заблокированы**, и ни одна страница не попыталась их сделать; локальные шрифты загрузились (Cormorant Garamond, Old Standard TT, Onest);
   * в меню подсвечивается текущий пункт на внутренних страницах;
   * фильтр RU: без фильтра видно 10 карточек, «легато» — 1, туба — 4, тромбон — 6, бессмысленный запрос — 0 и «Ничего не найдено»; фильтр EN даёт те же числа («Showing n of 10»). Проверялась **фактическая видимость карточек**, а не только счётчик;
   * переходы: EN из главной ведёт на `en/index.html`, RU оттуда обратно на `index.html`; карточка «Школы» ведёт на `schools.html`; первая сноска на `biography.html` ведёт на `about.html#s2`, и цель видна на экране.

### НЕ выполнялось

* Доступность внешних ссылок: ни одна внешняя ссылка не открывалась в этой проверке.
* Размещение на реальном сервере и открытие сайта по адресу blazhevich.space (домен и DNS подключает заказчик), работа HTTPS, перенаправлений и `index.html` для каталога `/en/`.

* Независимая проверка фактов и прав на изображения и нотные издания. Пометка в тексте «открывались и читались целиком» означает только, что автор текста открывал эти страницы при подготовке. Это не проверка.

## 7. Известные ограничения

* **Портрет** (`assets/blazhevich-portrait.webp`, 1024×1536, и `blazhevich-portrait-683.webp`) — художественное изображение, созданное с помощью ИИ по мотивам фотографии 1903 года; файл предоставлен заказчиком. Тонирован в одну гамму с архивными снимками консерватории и Большого театра. Это не историческая фотография, что указано в подписи и в «О проекте». Тромбон лежит горизонтально на верхней линейке надписи BLAZHEVICH — встроенный SVG-рисунок (`svg.tbn-lie`) в `src/ru/hero.html` и `src/en/page.html`; правильная геометрия, кулиса строго прямая.
* **Английская версия** — перевод, сделанный при подготовке сайта. Носитель языка её не вычитывал. Раздел «О проекте» в ней короче русского.
* Old Standard TT используется только для надписи и логотипа; кириллица в нём есть.
* Энциклопедия «Кругосвет» [8] не открылась (сервер отклоняет подключение). Её сведения совпадают с источниками [1], [2], [7], но сама она не прочитана. Не открылись также требования к прослушиваниям Бостонского университета (404) и Университета Джорджии (перенаправление на закрытый адрес). Поэтому утверждения о номерах этюдов в этих требованиях, о «библии этюдов в ключах» и цитата Майкла Малкахи с сайта удалены.
* Написание бренда изменено с прежнего «Blszhecich» на «Blazhevich» по указанию владельца.
* Нет страницы 404 и настроек сервера: это задача размещения.
* Каталог нот начальный (10 позиций), это не полный перечень сочинений.

## 8. Оставшиеся задачи

1. Собрать публичную версию с реальным адресом (раздел 2), запустить `tools/check_site.py`, загрузить содержимое `site/` на сервер (README.md).
2. На сервере настроить HTTPS, перенаправление http → https, `index index.html`, при желании страницу 404.
3. Портрет менять не требуется. Если понадобится другой, замените `assets/blazhevich-portrait*.webp` (вертикальный 2:3, желательно тонированный так же — см. «Изменения в этой передаче») и пересоберите.
4. После публикации проверить внешние ссылки и превью в Telegram, добавить сайт в Яндекс Вебмастер и Google Search Console с `D/sitemap.xml`.
5. При желании отдать английскую версию на вычитку носителю языка.
